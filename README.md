# Property waiting time tool

_Purpose_

This tool was created for Monmouthshire Housing Association as part of a freelance project. 
It aims to give information to potential tennants about previous wait times for property allocation, specifically for those in similar circumstances to them. 
Thousands of previous lettings records are filtered according to user entered data (area, number of bedrooms, priority, age, etc.) in order to provide the most accurate predictions. 

_Tecnhologies_

The backend is written in Flask Python with some additional JavaScript, and the frontend is pure HTML/CSS. 
It is then containerised using Docker. 
All records are anonymised and stored in a JSON file.
The UI is modern and responsive, adapting its layout for both mobile and desktop use.
